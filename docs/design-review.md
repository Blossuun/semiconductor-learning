# 디자인 비평: 배포 화면 (T-18)

- 대상: https://blossuun.github.io/semiconductor-learning/ 의 홈, `/tour/`, `/glossary/`, `/demo/step-animation/`
- 확인 조건: 데스크톱 1024px, 모바일 375px, 라이트·다크
- 심각도: 🔴 치명 / 🟡 보통 / 🟢 사소

## 전체 인상
뼈대(헤더·사이드바·다크 모드)와 접근성 기본기는 갖춰졌지만, 홈이 임시 링크 목록이고 내비게이션이 비어 있어 "학습 사이트"로 읽히지 않는다. 가장 큰 기회는 내비게이션·홈·용어 카드 밀도다.

## 시각 위계
- 먼저 보이는 것: 홈은 빈 회색 사이드바, 투어는 그림, 용어집은 첫 카드. 홈만 잘못됐다.
- 읽는 순서: 투어는 제목→안내→그림→캡션→버튼으로 자연스럽다. 용어집은 카드가 길어 두 번째 용어부터 스크롤이 필요하다.

## 접근성
- 색 대비: 본문 `#1b2330`/`#fff`, 보조 글자 `#5b6676`/`#f5f7fa`, 강조 `#1f5fd1`/`#fff` 모두 4.5:1 이상으로 보인다. 다크 팔레트도 통과.
- 터치 타깃: 미달(C8).
- 가독성: 본문 16px/1.75는 적절. 입력 14px(G4), 모바일 SVG 라벨(T4)이 작다.
- 대체 텍스트: SVG에 `role="img"`와 이름이 있다. 대체 텍스트 없는 이미지는 없다.

## 잘된 점
- 본문 건너뛰기 링크, 언어별 `lang` 속성, 장면 전환 `aria-live`가 있다.
- 다크 모드가 모든 화면과 SVG에서 깨지지 않는다.
- 모바일에서 가로 스크롤이 생기지 않는다.
- 색·간격·글꼴이 CSS 변수로 이미 정리돼 있어 디자인 시스템 교체가 쉽다.
- 투어 문장이 짧고 입문자 눈높이에 맞다.

## 우선순위
1. **내비게이션과 사이드바** (C1·C2·C3) — 지금은 길을 찾을 수단이 없다. T-21에서 처리.
2. **홈 화면** (H1·H2·H3) — 사이트 목적과 학습 경로를 첫 화면에 둔다. T-22에서 처리.
3. **용어 카드 밀도와 위계** (G1·G2) — 51개(앞으로 더 늘어남)를 훑을 수 있게 한다. T-25·T-26에서 처리.
4. **시각 정체성과 글자 단계** (C4·C5) — T-19 디자인 시스템에서 확정.
5. **터치 타깃·입력 글자 크기** (C8·G4) — T-19 컴포넌트 규칙에 포함.

### 남은 문제: 0개 (자동 점검 기준)
자동 점검은 다섯 화면, 두 폭, 두 테마에서 모두 통과했다.

### 이 점검이 다루지 못한 것
- 스크린 리더(NVDA, VoiceOver) 실제 낭독, 키보드만으로 전체 흐름 조작, 200% 확대는 확인하지 않았다.
- 투어 2~8장면과 포토 2~5단계는 모바일에서 라벨이 겹치는지 눈으로 확인하지 않았다(1장면·1단계만 확인).
- 배포 주소가 아니라 로컬에서 확인했다.

### 디자인 문서와 다른 채로 남은 것 (접근성 문제는 아님)
- StepAnimation: 캡션(번호·제목·설명)과 마지막 장면의 다음 학습 링크는 새 prop이 필요해 넣지 않았다.
- 포토 공정 레슨으로 가는 링크가 홈·목차에 없다(4단계가 "준비 중"으로 표시됨). 주소로만 열린다.
- 푸터 저장소 링크는 주소를 받지 못해 비어 있다. 파비콘이 없다.
