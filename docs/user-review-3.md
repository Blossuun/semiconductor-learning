# 3차 사용자 리뷰 (2026-11-15)

개발 서버(`localhost:4321/semiconductor-learning/`)를 브라우저로 열어 입문자 입장에서 직접 써 본 결과다.
후속 작업은 `TASKS.md` 7절(T-120~T-126)에 있다.

## 1. 확인한 범위

| 항목 | 방법 |
|---|---|
| 첫 화면, 투어 8장면 | 데스크톱 폭에서 직접 클릭 |
| 레슨 | 도체·부도체·반도체, 도핑, 포토 공정, 식각은 화면에서 직접 조작. MOSFET, 수율, HBM4, 현장 은어, 회의·보고 문장은 본문 전체를 읽음. 나머지 19개는 구성(그림 수, 영상, 용어 수, 문제 수, 본문 길이)만 확인 |
| 용어집 | 검색 15개 질의, 단계 필터, 용어 맞히기, `#term-silicon` 바로가기 |
| 설정 | 함께 볼 언어, 다크 모드, 진도 저장, 새로고침 후 유지 |
| 휴대폰 폭(375×812) | 식각 레슨, 목차 서랍, 용어 카드, 다크 모드 |

확인하지 못한 것

- 유튜브 영상 재생 (요청에 따라 틀지 않음. 미리보기 이미지와 제목, 출처 표시만 확인)
- 발음 듣기 소리. 이 브라우저에는 한국어 음성만 있어 영어·일본어·중국어 재생 결과를 알 수 없다
- 빌드 결과물과 GitHub Pages 배포본, 실제 휴대폰, Safari
- 용어 표기의 정확성 (T-113 범위)

## 2. 전체 평가

입문자가 "칩이 어떻게 만들어지는가"를 처음부터 끝까지 한 번 훑는 용도로는 지금도 쓸 만하다.
투어 → 기초 원리 → 공정 → 현장 말 순서가 자연스럽고, 레슨마다 구성이 같아 두세 개만 보면 읽는 법이 익는다.
부족한 쪽은 "익힌 것을 남기는 장치"다. 문제는 쉽고, 복습 수단은 뜻풀이→용어 한 방향뿐이며, 외국어 표기를 떠올려 보는 연습이 없다.
그래서 지금 상태로는 "읽고 이해했다"까지는 가지만 "4개 국어로 용어를 쓸 수 있다"까지는 가기 어렵다.

## 3. 좋았던 점

1. 첫 화면에서 할 일이 분명하다. 버튼 2개와 학습 경로 0~8단계가 한 화면에 들어오고, 단계를 누르면 레슨 28개에 모두 닿는다.
2. 투어 8장면이 짧고 그림이 뜻을 전한다. 장면마다 "왜 하는가"가 한 문장씩 있고, 핵심 용어가 고른 언어로 붙어 용어집으로 이어진다.
3. 레슨 구성이 일정하다. 한 줄 요약 → 비유 → 단계 그림 → 왜/어떻게/앞뒤 연결 → 더 깊이 → 용어 → 문제 순서가 28개 모두 같다.
4. 비유가 그림과 맞는다. 첫 레슨의 수도관(열린 관, 막힌 관, 밸브 달린 관)은 글과 그림이 같은 이야기를 한다.
5. 어려운 내용은 접혀 있다. 에너지 띠, 문턱 전압, 결함 밀도 같은 내용이 "더 깊이 알아보기"에 들어 있어 처음 읽는 사람이 막히지 않는다.
6. 용어 카드에 예문이 있다. 뜻, 현장 메모, 언어별 표기·읽기·예문이 한 카드에 있고 예문이 실제 현장 상황(보류, 폐기 판정 등)이다.
7. 8단계가 다른 입문 자료와 구별된다. "다운", "핫랏", "컨탐" 같은 말과 회의·보고 문장을 4개 국어로 준다.
8. 언어 선택이 모든 화면에 바로 반영되고 새로고침 뒤에도 유지된다.
9. 용어집 검색이 한국어, 영어, 일본어, 중국어, 약어, 현장 표현 모두에 걸린다 ("ウェーハ", "晶圆", "歩留", "핫랏", "foup" 모두 결과 있음).
10. 진도 표시가 완료 즉시 목차에 반영되고(1/4 → 2/4) 새로고침 뒤에도 남는다.
11. 휴대폰 폭에서 가로 넘침이 없고, 목차 서랍이 열리고 Esc로 닫힌다. 다크 모드에서 그림과 카드 색이 깨지지 않는다.
12. 영상은 누르기 전에는 불러오지 않고 제목과 출처가 적혀 있다.

## 4. 문제점

### 4.1 잘못 동작하거나 내용이 어긋난 것

| 번호 | 위치 | 내용 |
|---|---|---|
| P1 | 8단계 레슨 순서 | 목차 순서는 현장 약어 → 회의·보고 문장 → 현장 은어다. 그런데 현장 은어 본문은 "다음 레슨에서는 이 말들을 모아 회의에서 보고하는 문장을 연습합니다"라고 한다. 현장 은어가 마지막이라 "다음 레슨" 버튼도 없다. 은어를 배우기 전에 은어가 든 보고 문장을 먼저 만난다 |
| P2 | 헤더 "함께 볼 언어" | 메뉴를 연 뒤 Esc를 눌러도, 바깥을 눌러도 닫히지 않는다. 버튼을 다시 눌러야만 닫혀 본문 오른쪽 위를 계속 가린다 |
| P3 | 헤더 "전체" 체크박스 | (정정, T-121에서 확인) 문제 아님. 체크박스가 "전체" 글자를 감싼 `label` 안에 있어 이름은 "전체"로 읽힌다. "on"은 점검 도구가 `value` 값을 보여 준 것이었다 |
| P4 | 용어집·용어 맞히기 단계 필터 | 용어가 0개인 "0단계 칩 하나 만들어 보기"가 목록과 버튼에 남아 있다. 용어 맞히기에서 누르면 "보기 4개를 만들 수 없습니다"가 나온다 |
| P5 | 포토 공정 레슨 | 단계 그림에 설명이 없다. 다른 27개 레슨은 그림마다 "무엇을 보는가 / 왜 하는가" 두 문장이 붙는데 여기만 "1. 감광액 도포" 제목뿐이다. 그림 위쪽 빈 공간도 크다 |
| P6 | 포토 공정 레슨 용어 | 본문은 "선폭(CD)"이라 쓰고 용어 목록은 "임계 치수"다. 투어와 용어집 표제어는 "감광액"인데 본문은 "포토레지스트"로만 쓴다. 입문자는 같은 것인지 알 수 없다 |

### 4.2 학습 효과를 깎는 것

| 번호 | 위치 | 내용 |
|---|---|---|
| L1 | 레슨 확인 문제 | 오답 보기가 너무 쉽다. "물질의 색깔 이름", "원자가 없다", "가격이 가장 비싸서", "열에 닿으면 녹는 물질" 같은 보기는 본문을 읽지 않아도 지울 수 있다. 문제 5개가 이해 확인 구실을 못 한다 |
| L2 | 레슨 확인 문제 | 한 번 고르면 다시 풀 수 없고, 맞힌 개수도 나오지 않는다. 새로고침하면 기록이 사라진다 |
| L3 | 용어 맞히기 | 오답 보기를 108개 전체에서 뽑아 단계가 다른 말이 섞인다 (경고 뜻풀이에 MOSFET, electron). 소거법으로 풀린다 |
| L4 | 용어 맞히기 | 방향이 "뜻풀이 → 용어" 하나뿐이다. "한국어 용어 → 일본어 표기" 같은 외국어 떠올리기 연습이 없다. 사이트 이름이 4개 국어 학습인데 외국어를 실제로 시험하는 곳이 없다 |
| L5 | 용어 맞히기 | 틀린 용어를 모아 다시 내지 않고, 점수가 저장되지 않는다 |
| L6 | 레슨 본문 | "단계별로 보기" 설명과 "어떻게 하는가" 목록이 거의 같은 문장이다 (MOSFET, 수율, HBM4에서 확인). 같은 내용을 두 번 읽게 된다 |
| L7 | 레슨 본문 | 숫자가 거의 없다. 온도, 두께, 선폭 단위, 웨이퍼 지름 같은 감을 잡을 숫자가 없어 읽고 나도 규모가 그려지지 않는다. 본문 분량도 레슨당 850~1,000자로 짧다 |
| L8 | 첫 화면 | "이어서 학습" 버튼과 전체 진도(예: 5/28)가 없다. 다시 들어오면 단계를 하나씩 펼쳐 어디까지 했는지 찾아야 한다. 완료한 레슨에 표시도 없다 |
| L9 | 발음 듣기 | 기기에 해당 언어 음성이 없을 때 어떻게 되는지 안내가 없다. 이 브라우저에는 한국어 음성만 있었다. 버튼이 조용히 실패하면 사용자는 고장으로 본다 (소리는 확인 못 함) |

### 4.3 사소한 것

| 번호 | 내용 |
|---|---|
| M1 | 투어와 단계 그림의 장면 전환이 1초 넘게 걸린다. "다음"을 빠르게 누르면 앞 장면 글자가 겹쳐 보인다 |
| M2 | 용어집 검색이 부분 일치라 "PR"을 치면 관계없는 용어 5개가 나온다. 병음("jing")으로는 찾지 못한다 |
| M3 | 번체 중국어 읽기가 병음이다. 대만 사용자에게는 주음이 익숙하지만 한국인 학습자에게는 병음이 낫다. 지금대로 둔다 |
| M4 | 영상 미리보기 이미지를 `i.ytimg.com`에서 불러온다. "외부 이미지 금지" 규칙의 예외로 볼지 정해 둘 필요가 있다 |
| M5 | 개발 서버 주소(`localhost:4321/`)를 그대로 열면 404가 나온다. 배포본과는 관계없다 |
| M6 | 본문과 화면 글자는 한국어뿐이다. 한국어를 읽는 사람만 쓸 수 있다는 점을 첫 화면에서 밝히지 않는다 |

## 5. 학습을 끝내면 어디까지 가능한가

분량은 투어 5분, 레슨 28개 × 8~10분으로 4~5시간이다. 이틀이면 끝난다.

### 할 수 있게 되는 것

- 모래에서 패키지까지 공정 순서를 빠뜨리지 않고 말하고, 각 공정을 "무엇을, 왜 하는가" 한두 문장으로 설명한다.
- 도체/반도체, 도핑, PN 접합, MOSFET이 어떻게 이어져 스위치가 되는지 비유 수준으로 설명한다.
- 메모리와 로직, IDM·팹리스·파운드리·OSAT의 차이를 구분한다.
- 수율, 계측, 검사, EDS가 왜 있는지와 서로의 관계를 안다.
- HBM, TSV, 하이브리드 본딩, EUV, GAA가 뉴스에 나오면 무슨 이야기인지 따라간다.
- 용어 108개를 한국어로 듣고 뜻을 떠올린다. 영어 표기는 대부분 읽고 알아본다.
- 현장 약어와 은어(FOUP, WIP, TAT, 다운, 핫랏, 컨탐, 인터락)를 들었을 때 알아듣는다.
- 회의·보고 문장 카드를 보면서 4개 국어로 짧은 현황 보고를 읽는다.

비유하면 비전공 신입 사원이 입사 첫 주에 받는 공정 개론 교육을 마친 정도다.
기업 블로그와 반도체 기사를 사전 없이 읽고, 비전공 직무(영업, 구매, 통번역, 사무) 면접에서 "8대 공정을 설명해 보세요"에 답할 수 있다.

### 아직 안 되는 것

- 공정 조건과 숫자. 온도, 압력, 가스 종류, 두께, 선폭을 다루지 않아 공정·설비 엔지니어 직무 면접의 전공 질문에는 답하지 못한다.
- 장비 구조와 불량 유형. 설비 이름과 부품, 결함 종류별 원인 추정은 범위 밖이다.
- 소자 물리 계산. 에너지 띠와 문턱 전압은 말로만 소개한다.
- 외국어로 말하고 쓰기. 일본어·중국어 표기는 본 적이 있는 수준에 머문다. 떠올리는 연습과 반복 장치가 없어서, 한 번 읽고 일주일 뒤에 남는 양은 적을 것이다.
- 실제 회의 참여. 문장 카드를 읽는 것과 듣고 답하는 것은 다르다.

### 한 단계 올리려면

L1·L3·L4·L5를 고치면 "알아본다"가 "떠올린다"로 바뀐다. 같은 콘텐츠로 도달 수준이 가장 많이 오르는 지점이다.
L7(숫자 보강)은 그다음이며 레슨 28개를 다시 손봐야 해서 이번에는 넣지 않았다.
