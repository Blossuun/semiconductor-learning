# 사양

## 목표
반도체 지식이 없는 사람이 기초부터 공정 전체를 익혀, 업계 사람들과 공장(팹) 현장에서 소통할 수 있게 한다.
용어와 표현은 한국어·영어·일본어·중국어(간체·번체)로 함께 익힌다.

## 대상 학습자
- 고등학교 물리·화학 수준, 반도체는 처음
- 먼저 전체를 따라 해 본 뒤 원리를 깊게 이해하는 순서

## 요구사항
- 이미지·모션·동영상이 포함된 세련된 교육자료
- 누구나 이해할 수 있는 쉬운 표현
- GitHub 공개·배포, 다른 사람도 사용 가능
- 학습 진도는 localStorage, 반응형, 다크/라이트 모드

## 커리큘럼
0. 칩 하나 만들어 보기 — 모래에서 칩까지 따라가는 투어
1. 기초 원리 — 도체·부도체·반도체, 도핑, PN 접합, 트랜지스터(MOSFET)
2. 제품과 산업 — DRAM·NAND·HBM vs 로직, IDM·팹리스·파운드리·OSAT·소부장
3. 팹과 클린룸 — 공장 구조, 방진복, 웨이퍼 이송
4. 전공정 — 웨이퍼, 산화, 포토, 식각, 증착, 이온주입, 금속배선, CMP·세정
5. 계측·검사·수율
6. 후공정 — EDS, 패키징, TSV·HBM 적층, 하이브리드 본딩
7. 최신 기술 — EUV, GAA, HBM4
8. 현장 소통 — 약어, 현장 은어, 회의·보고 문장 (4개 국어)

참고: "8대 공정"은 삼성의 입문용 분류이며 업계 표준 규격이 아니다. 현장 구분(전공정/후공정, FEOL/BEOL)을 함께 가르친다.
