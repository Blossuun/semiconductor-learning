지시받은 작업 1개만 수행한다. 다른 작업 에이전트가 동시에 돌고 있다고 가정한다.

## 규칙
- 지시문에 적힌 "읽을 파일"만 읽고, 작업에 적힌 범위의 파일만 만들거나 고친다. 저장소를 탐색하지 않는다. 지시문이 따로 허용한 Grep 범위와 만들 파일(예: 수치 대조표 `.claude/tmp/checks/T-번호.md`)은 예외다.
- 지시문에 "실수 방지 점검"이 붙어 있으면 보고 전에 작업자 몫 항목을 모두 수행한다. 하지 못한 항목이 있으면 `완료`가 아니라 `실패`로 보고한다.
- 큰 파일은 Grep으로 위치를 찾고 필요한 줄만 읽는다.
- 범위 밖 파일을 고쳐야 하면 고치지 말고 "승인 필요"로 보고하고 끝낸다.
- `TASKS.md`를 고치지 않는다. 완료 표시는 본 세션이 한다.
- `src/data/glossary.yaml`을 직접 고치지 않는다(지시문이 허용한 경우만 예외). 새 용어는 `.claude/tmp/terms/T-번호.yaml`에 `.claude/skills/term/SKILL.md`의 스키마로 쓴다. 쓰기 전에 Grep으로 glossary.yaml에 같은 id가 있는지 확인한다.
- 빌드, 설치, 커밋을 하지 않는다.
- 웹 검색은 작업에 "검색 필요"가 있을 때만 한다.
- 요청받지 않은 리팩터링·기능·문서를 추가하지 않는다.
- 외부 이미지·문장을 복사하지 않는다. 도해는 SVG로 직접 그린다. 컴포넌트는 Astro 단일 파일, 외부 UI 라이브러리 없이 쓴다.

## 보고 (3줄 이내)
- 1줄: `T-번호 완료` 또는 `T-번호 실패: 이유` 또는 `T-번호 승인 필요: 무엇`
- 2줄: 만들거나 고친 파일 경로
- 3줄: 본 세션이 알아야 할 것(없으면 생략). 수치 대조표처럼 길어지는 내용은 보고에 넣지 않고 지시받은 파일에 쓴다.
